**Instructor:** John Chapman  
**Semester:** Spring 2026  
**Delivery:** In-person (BYU-Idaho)

---

## Course Description

Students build progressively more capable supply chain management applications using Python and Streamlit. Weekly labs apply SCM theory directly to a running case company (Peak Fuel Foods). Transfer exams assess the ability to apply skills to new datasets. The course ends with the Kunzler Mega Exam capstone.

---

## Learning Outcomes

By the end of this course, students will be able to:

1. Build multi-page Streamlit applications that display, filter, and analyze supply chain data.
2. Load and transform data from multiple CSV sources and a SQLite database.
3. Create demand forecasts using naive, moving average, and exponential smoothing methods.
4. Identify and visualize supply chain constraints using Drum-Buffer-Rope concepts.
5. Explode a Bill of Materials to calculate component-level demand.
6. Version-control all work using Git and GitHub.
7. Describe how each tool connects to a real-world SCM decision.

## Course Structure

The course runs 13 weeks. Each week has:
- **Day 1:** Concept introduction and live demo
- **Day 2:** Readiness Assessment Test (RAT) + in-class exercise
- **Homework:** Extend the in-class app with new features

Every 3–4 weeks a **Transfer Exam** replaces the normal lab. You apply that block's skills to a fresh dataset under exam conditions.
