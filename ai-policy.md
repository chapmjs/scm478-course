# AI Tool Policy — SCM 478

---

## Philosophy

AI tools (ChatGPT, GitHub Copilot, Claude, etc.) are allowed and encouraged in this course — they are part of the modern SCM analyst's toolkit. The goal is not to avoid AI, but to use it in a way that builds your skills rather than replacing them.

**You are responsible for every line of code you submit.** If you can't explain it, you don't own it.

---

## What Is Allowed

- Using AI to explain concepts, error messages, or documentation
- Using AI to suggest code snippets that you then read, understand, and adapt
- Using AI to help debug code when you are stuck
- Using AI to check your logic or suggest improvements

---

## What Is Not Allowed

- Submitting AI-generated code that you have not read or cannot explain
- Using AI during a Transfer Exam (see below)
- Having AI complete an assignment for you without your engagement

---

## Transfer Exams

**AI tools are not permitted during Transfer Exams** unless explicitly stated in the exam instructions.

The exam is designed to assess what *you* can build. Using AI defeats the purpose and will be treated as an academic integrity violation.

---

## Disclosure

If you used AI substantially to help with an assignment, note it briefly in your Canvas submission comments — something like: "Used GitHub Copilot to help structure the SQLite query in app.py." This is not penalized; it builds good professional habits.

---

## The Core Test

Ask yourself: *"Could I rebuild this from scratch if asked?"*

If yes, you're using AI as a learning accelerator. If no, slow down — the exam is coming.
