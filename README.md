# SCM 478: Operations Analysis and Modeling
### Building SCM Systems with Python, Streamlit, and GitHub

**Instructor:** John Chapman  
**Semester:** Spring 2026  
**Practice Company:** Peak Fuel Foods  
**Capstone:** Kunzler Mega Exam

---

## Course Description

SCM 478 teaches you to build real supply chain management systems using Python, Streamlit, and GitHub. Each week you extend a working application for our practice company, **Peak Fuel Foods** — a regional sports nutrition manufacturer. By the end of the course you will have built a full SCM dashboard covering product catalogs, sales analytics, purchase order tracking, demand forecasting, inventory management, and constraint-based scheduling.

The course culminates in the **Kunzler Mega Exam**, where you apply every skill from the semester to a new dataset under exam conditions.
