All submissions are collected through **Canvas**. Due dates are listed there.

## Grade Breakdown

| Category | Weight | Notes |
|----------|--------|-------|
| Readiness Assessment Tests (RATs) | 15% | Short in-class quizzes, Day 2 each week |
| In-Class Exercises | 20% | Completed during lab; submitted same day |
| Weekly Homework | 25% | App extensions; graded on correctness and functionality |
| Transfer Exams (4 × 8%) | 32% | Individual; open-notes; new dataset each time |
| Participation | 8% | Engagement, peer help, clean commit history |
| **Total** | **100%** | |

## Homework Grading Rubric

Each homework is worth 10 points unless noted otherwise.

| Criterion | Points | Description |
|-----------|--------|-------------|
| Functionality | 5 | App runs without errors; all required features present |
| Correctness | 3 | Data logic, calculations, and outputs are accurate |
| Code quality | 2 | Code is readable; no redundant code; GitHub commit exists |

---

## Transfer Exams

Transfer exams are individual assessments. You will receive a new dataset and a spec sheet. You have the full class period to produce a working Streamlit app.

- **Open notes** and open to your own past code
- **Closed to other people** — no collaboration during the exam
- You may use AI tools under the terms in [ai-policy.md](ai-policy.md)

---

## Late Policy

- 0–24 hours late: 10% deduction
- 24–48 hours late: 20% deduction
- 48+ hours late: 50% deduction
- After graded and returned: not accepted

Contact the instructor **before** the deadline if you need an extension.
